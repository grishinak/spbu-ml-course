# spbu-ml-course

Этот репозиторий содержит выполненные мной практические задания в рамках курса по машинному обучению.

По ходу работы выполнялись в Google Collab, для локального запуска могут понадобится незначительные изменения.

## Список заданий

| № | Тема |
|---|------|
| 1 | Первичный анализ данных |
| 2 | Логистическая регрессия и SVM|
| 3 | Дискриминантный анализ LDA/QDA & Тематическое моделирование LSA/pLSA |
| 4 | Decision Tree/Random Forest & Optuna/GridSearch |
| 5 | Градиентный бустинг |
| 6 | Нейронные сети |
| 7 | Глубокое обучение |

Подробное описание задания находятся в ноутбуках решений.

## Структура репозитория:
```bash
.
├── HW1/                    # Первое домашнее задание
│   ├── EDA.ipynb           # Ноутбук с решением
│   └── data.csv.           # Специальные анные для задания (если есть)
├── HW2/                    # Второе домашнее задание
├── ...
└── README.md
└── Video_Games.csv         # Индивидуальный датасет для работы во всем курсе
```
